# Ostadchi Flutter v0.4

Flutter source for the Ostadchi skilled-workers marketplace prototype.

The project source is now arranged at the repository root so build services can identify it as a Flutter project. The Android platform scaffold still needs to be generated by Flutter before building:

```bash
flutter create --platforms=android .
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Current prototype: home page and service categories only. Phone OTP, database, worker profiles, reviews, contracts, and payments are not connected yet.
